## 下载与使用

1. 打开目标软件的版本说明页面。
2. 在页面底部的 **Assets** 区域下载对应的 `.exe` 或 `.zip` 文件。
3. 如果下载的是压缩包，请先完整解压，再运行其中的程序。
4. 涉及系统清理或磁盘恢复操作前，请先备份重要数据。

## 使用与安全提示

- 请仅处理您有权访问的数据与内容，并遵守相关法律、平台规则及版权要求。
- 使用磁盘恢复工具时，请立即停止向源磁盘写入新数据，并将恢复结果保存到其他磁盘。
- 系统清理效果会因 Windows 版本和使用环境而异，执行前请确认待清理项目。
- 建议只从本仓库的 Release 页面下载，避免使用来源不明的二次分发文件。
